## Обзор

Lazeal OptiX — инновационный проект в сфере медицинских технологий. Ядро проекта — разработка устройства, предоставляющего пользователям расширенную диагностику в домашних условиях. Используя передовые методы микроскопии и биохимического анализа, устройство нацелено на раннее выявление различных проблем со здоровьем, что способствует улучшению медицинских исходов.

Проект Lazeal OptiX возник из стремления снизить страдания и сделать диагностику здоровья более доступной для всех. Предоставляя людям инструменты для контроля собственного здоровья, мы стремимся помочь в создании более здорового общества.

Репозиторий в настоящее время ориентирован на исследования/прототипирование и рабочие процессы, построенные вокруг ноутбуков. Большинство деталей реализации и экспериментов отслеживаются в Jupyter-ноутбуках в `notebooks/`.

## Возможности

1. **Продвинутая микроскопия:** использование современных методов микроскопии для детального анализа.
2. **Биохимический анализ:** углубленный биохимический анализ позволяет выявлять различные показатели здоровья.
3. **Удобство для пользователя:** разработано для домашнего использования, предлагая простой и доступный интерфейс.
4. **Компактность и доступность:** Lazeal OptiX компактен и имеет доступную стоимость, делая расширенную диагностику доступной повседневным пользователям.
5. **Lensless workflows для реконструкции:** основанные на ноутбуках конвейеры вычислительной визуализации и реконструкции.
6. **Эксперименты по локализации источника света:** ноутбуки оптимизации для оценки позиции источника света.
7. **Утилиты сопоставления нескольких изображений:** ноутбук- и C++ OpenCV-процессы для feature matching/alignment.

### Примечания по модулям

- `camera/`: скрипты/ресурсы, связанные с использованием камеры для высокоразрешающего захвата образцов.

## Ноутбуки

Каталог `notebooks` содержит Jupyter-ноутбуки, документирующие различные аспекты проекта Lazeal OptiX. Эти ноутбуки включают код, визуализации и подробные объяснения методологий проекта. Они служат интерактивным способом изучения и понимания проекта.

### `light_source_location`

Каталог `light_source_location` содержит ноутбуки, связанные с оценкой расположения источника света. В этих ноутбуках представлены алгоритмы и методы, используемые для точной оценки позиции источника света, что является критически важным аспектом проекта Lazeal OptiX.

### `multiple_match`

Каталог `multiple_match` содержит ноутбуки и скрипты, связанные с сопоставлением нескольких изображений или паттернов. Эта часть проекта включает сложные алгоритмы для точного сопоставления и выравнивания изображений, что необходимо для реконструкции изображений высокого разрешения из lensless-системы визуализации.

### `reconstruction`

Каталог `reconstruction` содержит ноутбуки, связанные с реконструкцией изображений, полученных устройством Lazeal OptiX. Эти ноутбуки документируют передовые вычислительные методы, используемые для реконструкции изображений высокого разрешения из lensless-системы визуализации.

## Предварительные требования

- ОС: Linux/macOS рекомендованы для текущих workflows на ноутбуках и OpenCV.
- Python: предоставленный файл окружения рассчитан на **Python 3.7**.
- Conda: необходим для воспроизведения документированного окружения `lensless`.
- Jupyter Notebook/Lab.
- Необязательный C++ toolchain для `multiple_match.cpp`:
  - `g++` с поддержкой C++17.
  - OpenCV 4.x с contrib-модулями (`opencv2/xfeatures2d.hpp` / SIFT).

## Установка

### 1) Клонирование

```bash
git clone https://github.com/lachlanchen/lazealoptix.git
cd lazealoptix
```

### 2) Создание окружения для ноутбуков (рекомендуется)

```bash
conda env create -f notebooks/reconstruction/lensless.yaml
conda activate lensless
```

### 3) Запуск Jupyter

```bash
jupyter notebook
```

## Использование

Этот репозиторий в основном используется через открытие ноутбуков и последовательный запуск ячеек.

### Трек реконструкции

- Откройте `notebooks/reconstruction/dataset_prep.ipynb` для подготовки датасета.
- Откройте `notebooks/reconstruction/lensless-dropout-one-led-mahuichong.ipynb` для экспериментов по реконструкции/обучению.

### Трек локализации источника света

- Откройте ноутбуки в `notebooks/light_source_location/`.

### Трек multiple match

- Откройте ноутбуки в `notebooks/multiple_match/`.
- Необязательная C++ утилита: `notebooks/multiple_match/multiple_match.cpp`.

## Конфигурация

### Окружение Conda

Основная спецификация окружения находится по адресу:

- `notebooks/reconstruction/lensless.yaml`

Заметные сигналы зависимостей из этого файла включают:

- `python=3.7`
- `pytorch=1.9.0`
- `pyro-ppl`
- связанные с `opencv` зависимости для workflow компьютерного зрения в ноутбуках

### Данные и пути

- **Предположение:** ноутбуки ожидают локальные датасеты/файлы, которые централизованно не объявлены в корне репозитория.
- **Предположение:** C++ утилита сопоставления ожидает каталог `all/` (относительно пути выполнения), содержащий изображения, читаемые как grayscale.

Если ваша локальная конфигурация отличается, соответствующим образом обновите ячейки путей в ноутбуках и входной каталог C++.

## Примеры

### Запуск утилиты сопоставления (пример)

```bash
cd notebooks/multiple_match
g++ -std=c++17 multiple_match.cpp -o multiple_match `pkg-config --cflags --libs opencv4`
./multiple_match
```

Ожидаемое поведение:

- Считывает изображения из `all/`
- Вычисляет последовательные SIFT-based совпадения между изображениями
- Записывает выходное изображение с именем вида `result_<timestamp>.png`

### Запуск конкретного ноутбука

```bash
conda activate lensless
jupyter notebook notebooks/reconstruction/dataset_prep.ipynb
```

## Примечания по разработке

- В репозитории сейчас нет пакетирования на уровне корня (`pyproject.toml`, `requirements.txt` или `setup.py`) и нет CI/тестового контура на уровне корня.
- Работа в первую очередь ориентирована на эксперименты: ноутбуки являются source-of-truth для большинства алгоритмов.
- `camera/`, `light_source/`, `reconstruction/` и `three_axis_cnc/` сейчас содержат высокоуровневые описания модулей и со временем могут быть расширены runbook-документацией.
- `i18n/` существует и зарезервирован для многоязычных вариантов README.

## Устранение неполадок

- **Проблемы решения зависимостей Conda:** обновите Conda и повторите создание окружения.
- **Несовпадение kernel в ноутбуках:** убедитесь, что активное ядро соответствует `lensless` там, где это требуется.
- **Ошибки компиляции OpenCV/SIFT:** установите OpenCV contrib modules и проверьте доступность `opencv2/xfeatures2d.hpp`.
- **Ошибки file-not-found в ноутбуках:** проверьте пути к датасетам и относительные каталоги, ожидаемые ячейками ноутбуков.
- **C++ matcher не считывает изображения:** убедитесь, что `notebooks/multiple_match/all/` существует и содержит корректные файлы изображений.
