## Обзор

Lazeal OptiX — это исследовательско-прототипный проект для беслинзовых методов визуализации в диагностике, смежной со здравоохранением. Репозиторий сейчас ориентирован на ноутбуки и эксперименты, и призван сделать передовые диагностические подходы более доступными в условиях с ограниченными ресурсами.

Ключевые идеи:

- беслинзовая реконструкция изображений;
- локализация источника света;
- сопоставление и выравнивание нескольких изображений.

Основная поддержка проекта ведётся через Jupyter-ноутбуки в каталоге `notebooks/`, а контент по модулям хранится в специализированных директориях.

## Возможности

1. **Продвинутые микроскопические концепции**: расширенные оптические подходы и шаблоны захвата изображений для детального анализа.
2. **Биохимический / диагностический контекст**: экспериментальные рабочие процессы, ориентированные на поиск маркеров состояния здоровья.
3. **Домашний сценарий применения**: проектирован для удобного применения и практического развёртывания.
4. **Опыт с ноутбука в первую очередь**: Jupyter-ноутбуки являются основным путём запуска.
5. **Инструменты беслинзовой реконструкции**: вычислительные пайплайны для высокоточной реконструкции.
6. **Инструменты локализации источника света**: эксперименты по локализации источника и геометрической калибровке.
7. **Многократное сопоставление изображений**: методы SIFT на основе сопоставления, построения цепочек и выравнивания.

### Примечания по модулям

- `camera/`: скрипты/ресурсы для работы с камерой при высокоточным захвате образцов.
- `light_source/`: скрипты/ресурсы для управления источником света и оптимизации.
- `reconstruction/`: скрипты/ресурсы для вычислительной реконструкции.
- `three_axis_cnc/`: скрипты/ресурсы для позиционирования и управления трёхосевым ЧПУ.
- `notebooks/`: основное техническое пространство для экспериментов и методов.

## Ноутбуки

Каталог `notebooks` содержит Jupyter-ноутбуки, описывающие основные экспериментальные методы. Эти ноутбуки содержат код, визуализации и пояснения методик для каждого направления.

### `light_source_location`

Содержит ноутбуки, относящиеся к оценке местоположения источника света. Эти методы поддерживают геометрическую калибровку источника и точность реконструкции.

### `multiple_match`

Содержит ноутбуки и скрипты для сопоставления изображений/паттернов и выравнивания, поддерживающие устойчивые рабочие процессы регистрации.

### `reconstruction`

Содержит ноутбуки по реконструкции по захваченным изображениям, включая этапы предварительной обработки и скрипты экспериментов.

## Предварительные требования

- ОС: для текущих рабочих процессов Conda и OpenCV рекомендуется Linux/macOS.
- Python: окружение ориентировано на **Python 3.7**.
- Conda: требуется для воспроизведения документированного окружения `lensless`.
- Jupyter Notebook/Lab.
- Дополнительный C++ toolchain для `multiple_match.cpp`:
  - `g++` с поддержкой C++17.
  - OpenCV 4.x с модулями contrib (`opencv2/xfeatures2d.hpp` / SIFT).

## Установка

### 1) Клонирование

```bash
git clone https://github.com/lachlanchen/lazealoptix.git
cd lazealoptix
```

### 2) Создание окружения для ноутбуков

```bash
conda env create -f notebooks/reconstruction/lensless.yaml
conda activate lensless
```

### 3) Запуск Jupyter

```bash
jupyter notebook
```

## Использование

Репозиторий в первую очередь используется путём открытия ноутбуков и запуска ячеек в задокументированной последовательности.

### Трек реконструкции

- Откройте `notebooks/reconstruction/dataset_prep.ipynb` для подготовки датасета.
- Откройте `notebooks/reconstruction/lensless-dropout-one-led-mahuichong.ipynb` для экспериментов по реконструкции/обучению.

### Трек локализации источника света

- Откройте ноутбуки в `notebooks/light_source_location/`.

### Трек множественного сопоставления

- Откройте ноутбуки в `notebooks/multiple_match/`.
- Дополнительно: утилита `notebooks/multiple_match/multiple_match.cpp`.

## Конфигурация

### Окружение Conda

Основная спецификация окружения:

- `notebooks/reconstruction/lensless.yaml`

Ключевые зависимости включают:

- `python=3.7`
- `pytorch=1.9.0`
- `pyro-ppl`
- зависимости компьютерного зрения, используемые с OpenCV, в ноутбуках

### Данные и пути

- **Допущение:** датасеты локальные и централизованно не объявлены в корне репозитория.
- **Допущение:** утилита `multiple_match.cpp` ожидает каталог `all/` (относительно текущей рабочей директории её запуска), содержащий изображения, доступные для чтения в градациях серого.

Если локальная конфигурация отличается, обновите пути в ячейках ноутбуков и входной каталог для C++ соответственно.

## Примеры

### Запуск утилиты сопоставления

```bash
cd notebooks/multiple_match
g++ -std=c++17 multiple_match.cpp -o multiple_match `pkg-config --cflags --libs opencv4`
./multiple_match
```

Ожидаемое поведение:

- Читает изображения из `all/`
- Вычисляет цепочки сопоставлений на основе SIFT между изображениями
- Записывает изображение результата с именем вида `result_<timestamp>.png`

### Запуск конкретного ноутбука

```bash
conda activate lensless
jupyter notebook notebooks/reconstruction/dataset_prep.ipynb
```

- `i18n/` подготовлен для локализованной документации.

## Устранение неполадок

- **Проблемы решения зависимостей Conda:** обновите Conda, проверьте порядок каналов и повторите создание окружения.
- **Несоответствие ядра в ноутбуках:** убедитесь, что Jupyter использует окружение `lensless`.
- **Ошибки компиляции OpenCV/SIFT:** установите модули OpenCV contrib и проверьте наличие `opencv2/xfeatures2d.hpp`.
- **Ошибки «файл не найден» в ноутбуках:** проверьте ожидаемые датасеты и пути относительно ноутбуков.
- **Matcher не читает изображения:** убедитесь, что `notebooks/multiple_match/all/` существует и содержит корректные файлы изображений.
